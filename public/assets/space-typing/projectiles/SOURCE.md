# Player Projectile Atlas V1

Runtime asset: `player-projectiles-v1.webp`

- Generated from the owner-approved 12-projectile concept direction using the
  image-generation workflow; the generated/cropped art is the authoritative
  projectile body.
- Canvas code is intentionally limited to motion/effect layers and fallback.
- Atlas layout: 3 columns x 4 rows, each cell 256x128.
- Order:
  1. Meteor Bolt
  2. Crescent Slash
  3. Prism Dart
  4. Nova Pearl
  5. Twin Star Shot
  6. Halo Burst
  7. Thunder Needle
  8. Blossom Comet
  9. Void Spike
  10. Solar Lance
  11. Tidal Pearl
  12. Aurora Ribbon

The runtime must not replace these generated bodies with procedural shapes
unless the atlas fails to load.
