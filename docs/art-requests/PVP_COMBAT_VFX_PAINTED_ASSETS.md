# PVP COMBAT VFX — PAINTED ASSET PROMPT PACK

**Target folder:** `art-src/combat-vfx/`  
**Pipeline:** `pnpm combat-vfx:prepare`

## Critical delivery rule

**ONE GENERATION CALL = ONE REQUESTED FILE.**

Never create a collage, contact sheet, sprite sheet, grid, storyboard or multi-panel image.

For every image:
- 1536x1536 or larger;
- pure black background `#000000`;
- no text;
- no UI;
- no frame/border;
- no ship body;
- cinematic sci-fi game VFX;
- bright additive-light look;
- highly detailed plasma/smoke/sparks;
- soft luminous falloff into black;
- keep the effect centered with enough empty black margin for automatic crop;
- no visible square edge.
